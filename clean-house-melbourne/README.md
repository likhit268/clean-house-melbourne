# Clean House Melbourne — Premium Website Redesign

A complete, premium, modern website redesign for **Clean House Melbourne**, a professional residential and home-services cleaning company operating across Melbourne, Victoria, Australia.

## Live Preview

Open `index.html` directly in your browser, or run the included PowerShell server:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then visit: [http://localhost:3000](http://localhost:3000)

## Features

- **Sticky navigation** with mobile drawer
- **Split hero** with inline booking/quote form
- **12-service grid** with interactive detail modals (inclusions, CTA)
- **Before/After drag slider** — post-renovation transformation
- **Reviews carousel** — real verified customer testimonials (swipe + dots)
- **Interactive pricing calculator** — Regular vs. Renovation + GST
- **Suburb service area checker** — live lookup for inner Melbourne suburbs
- **FAQ accordion** — 12 key policy questions
- **Contact & quote form** with validation and toast notifications
- **Mobile sticky CTA bar** — Get Quote / Call / SMS at bottom of screen
- **SEO optimised** — meta tags, semantic HTML, JSON-LD local business schema
